# แฟ้มเยี่ยมบ้าน Digital Home Visit — ฟอร์ม iPad (v1)

โฟลเดอร์นี้ = ระบบเก็บข้อมูลเยี่ยมบ้านแบบกรอกบน iPad แล้วส่งต่อเข้า LaTeX + สไลด์

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| **`homevisit_form_v1.html`** | ฟอร์มหลัก — เปิดบน iPad ได้เลย (ไฟล์เดียว ไม่ต้องอินเทอร์เน็ต) |
| `latex-reference/` | ต้นฉบับ LaTeX + PDF + font จาก Overleaf (สำรองไว้ ไม่ต้องแก้) |
| `README.md` | ไฟล์นี้ |

## วิธีใช้ฟอร์ม (iPad)

1. **ส่งไฟล์ `homevisit_form_v1.html` ไปยัง iPad** — ใช้ AirDrop, หรือบันทึกลง Files (iCloud Drive)
2. แตะไฟล์ → เปิดด้วย **Safari** (ถ้าถามให้เลือกแอป ให้เลือก Safari)
3. (แนะนำ) กดปุ่ม Share ใน Safari → **Add to Home Screen** → จะได้ไอคอนเปิดเหมือนแอป ใช้แบบเต็มจอ
4. กรอกข้อมูลระหว่างเยี่ยมบ้าน — **บันทึกอัตโนมัติทุกครั้งที่พิมพ์** (ข้อมูลอยู่ในเครื่อง ไม่ต้องกังวลปิดไป)
5. ถ้ากลับมาใช้งานครั้งหน้า ข้อมูลเดิมยังอยู่

## Export ข้อมูล

กดปุ่มล่างของฟอร์ม:

- **Export Markdown** → ข้อความสรุป (เฉพาะส่วนที่กรอก) ใช้ทำ **สไลด์** (Marp / Google Slides / Canva) หรือโน้ต
- **Export LaTeX** → ไฟล์ `.tex` สำเร็จรูป *compile ได้เลยใน Overleaf* (Compiler: XeLaTeX; project ต้องมี `fonts/` เหมือนเดิม) — ข้อความสรุปนี้เอาไปรวมกับ `main.tex` ฉบับเต็มก็ได้
- **🖨 พิมพ์** → พิมพ์เฉพาะส่วนที่มีข้อมูล (ถ้าเปิดบน iPad กด แล้วเลือก Save as PDF ได้)

กดปุ่ม **＋ ผู้ป่วยใหม่** เพื่อเริ่มข้อมูลคนใหม่ (แนะนำให้ Export JSON สำรองก่อน)

## วิธีใช้กับ Overleaf

1. เปิด Overleaf project เดิม (ที่มี `fonts/NotoSansThai-Regular.ttf`)
2. New file → `summary.tex` → วางเนื้อหาจาก **Export LaTeX**
3. ตั้ง Compiler เป็น **XeLaTeX** แล้ว compile

## เครื่องมือคัดกรองในฟอร์ม (คำนวณคะแนนอัตโนมัติ)

- **Thai Zarit Burden Interview (22 ข้อ)** — ภาระผู้ดูแล 0–88 คะแนน คิดให้อัตโนมัติ พร้อมการแปลผล 0–20/21–40/41–60/61–88
- **Modified Barthel ADL** — ฟอร์มนี้ใช้สเกล 0–20; คะแนน 0–20 หมายถึงพึ่งพาผู้ดูแลทั้งหมด (Total dependence); หมายเหตุ: Barthel Index แบบเต็มใช้สเกล 0–100 โดย 100 = Fully independent
- **2Q / 9Q (กรมสุขภาพจิต)** — คัดกรองภาวะซึมเศร้า: ตอบ 2Q ก่อน ถ้า "ใช่" ข้อใดข้อหนึ่งให้ทำ 9Q (แสดงไว้ครบ ไม่มีการซ่อน/ขยับฟอร์ม); 9Q ตัดสินผล 0–6 ปกติ · 7–12 น้อย · 13–18 ปานกลาง · ≥19 รุนแรง; ข้อ 9 (คิดฆ่าตัวตาย) ≥1 → แจ้งเตือนให้ประเมิน/ส่งต่อ
- คะแนน การแปลผล และสรุปคำตอบ ถูกบันทึกพร้อมกับข้อมูลอื่น และรวมอยู่ใน Export ทุกแบบ

## หมายเหตุ

- ข้อมูลทั้งหมดถูกเก็บในเครื่อง (localStorage ของเบราว์เซอร์) — **ไม่มีการส่งข้อมูลออกไปที่ใด**
- ฟอร์มนี้เป็นเครื่องมือบันทึก ไม่แทน clinical judgement
- โครงสร้างหัวข้อตรงกับ `main.tex` ฉบับเต็มทุก PART (INHOMESSS, ACP, caregiver, trajectory ฯลฯ)
